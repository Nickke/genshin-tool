# GenshinTool

Tool per analizzare l'inventario di Genshin Impact tramite file GOOD JSON generati da InventoryKamera.

## File

- **GenshinTool.html** — apri nel browser e carica il tuo JSON
- **inventorylists/** — file di configurazione per InventoryKamera (aggiornati a Ver 7.1)

## Come usare

1. Scarica `GenshinTool.html`
2. Aprilo nel browser
3. Carica il file GOOD JSON generato da InventoryKamera
4. Esplora inventario, eventi, abyss e consigli personaggi

## Aggiornamento database IK

Copia i file da `inventorylists/` nella cartella `inventorylists/` di InventoryKamera, sovrascrivendo quelli vecchi.
